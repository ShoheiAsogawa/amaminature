## 1. ひとことで言うと

**「奄美で出会った生き物を、LINEで撮って・名前をつけて・集める」図鑑サービス。**
観光客と住民の“楽しい記録”を、そのまま **ロードキル対策・生物調査のデータ** に変え、
行政・企業・観光事業者から収益を得る。ユーザーは基本無料、お金を払うのは「データと送客と協賛の価値を受け取る組織」。

```
 ユーザー（観光客・住民）          アマリンク（AMAMI NATURE）           お金を払う組織
 ─────────────────────         ──────────────────────────         ───────────────────
 撮る・名前をつける・集める  ──▶   記録・路上レポート・出現データ  ──▶  自治体・環境省・県（B2G）
 夜はゆっくり走る（宣言）    ──▶   安全運転の行動変容             ──▶  協賛企業（航空・損保・レンタカー等）
 ポイントで景品・割引        ◀──   景品原資（協賛・自治体）        ◀──  
 ナイトツアー等に参加        ──▶   送客                          ──▶  認定ガイド・体験事業者（手数料）
 AI判定をもっと使いたい      ──▶   AMAMI NATURE+（少額課金）
```

## 2. なぜ今、なぜ奄美か（市場と機会）

| 事実 | 数値・内容 | 事業上の意味 |
|---|---|---|
| 来島者数 | 2024年の奄美群島入込客数 **841,213人**（前年比+2.2%）、うち群島外からの入域客 **653,195人**。コロナ前（2019年）は891,351人 | 毎年65万人規模の「新規ユーザー候補」が島に来る |
| 空港旅客 | 2024年の奄美群島5空港の旅客数 **約135.7万人** | 空港・機内・レンタカーが最大の接点 |
| 世界自然遺産 | 2021年7月26日、奄美大島・徳之島が登録 | 「自然を楽しむ観光」が前提の島。保全とセットの観光が求められる |
| ロードキル | 2025年、アマミノクロウサギの死骸確認が過去最多の **284匹**、うち交通事故 **185匹**（奄美大島157・徳之島28） | 行政が予算をつけて解決したい課題。**夜間の運転行動を変える仕組み**に価値がある |
| 夜間の林道 | 三太郎線周辺で夜間通行の予約制（1時間4台）・観察ルールを試行 | ルール周知・遵守を後押しするツールが求められている |
| 外来種対策の成果 | 2024年9月、環境省が奄美大島のマングース根絶を宣言 | 「市民参加で守る」ストーリーが成立しやすい。再侵入監視・ノネコ対策など次の課題もある |
| ガイド市場 | 認定ガイドのナイトツアー **7,700〜8,000円**／人、マングローブカヌー **7,000円〜** | 送客1件あたり800〜1,200円（手数料10〜15%）が見込める単価 |
| LINE | 国内月間利用者 **1億人**（2025年12月） | アプリのインストール不要。観光客も友だち追加だけで使える |
| 競合 | 全国型の「Biome（バイオーム）」は自治体・鉄道会社と連携した生き物調査イベントの実績多数。**奄美特化の写真コレクションアプリは確認できず** | 全国型と組む／差別化する余地がある（後述） |

### 差別化（Biomeなど全国型との違い）

1. **LINEで完結**：アプリ不要。旅行者でも“その場で”始められる（全国型はアプリDLが前提）。
2. **奄美専用の図鑑とルール**：固有種・希少種・ハブ等の危険生物、金作原・三太郎線のルール、島の文化（ケンムン、なり味噌、えらぶゆり）まで一体。
3. **ロードキル対策に直結**：路上レポート（正確な位置は行政のみ）＋セーフドライブ宣言。**全国型にない、奄美の行政課題そのもの**に効く。
4. **送客まで一気通貫**：「この生き物に会える体験」→認定ガイドへ。
5. **希少種保護の設計**：希少種は座標を保存しない（サーバー側でも強制）。盗掘・密猟を助長しない。

## 3. プロダクト（LINE公式アカウント × LIFF）

| 機能 | 内容 | 収益とのつながり |
|---|---|---|
| 図鑑コレクション | 奄美の62種（哺乳類・鳥類・爬虫両生類・昆虫・海水辺・植物）。撮影→種を選ぶ→ニックネーム→カード獲得演出 | 継続利用・SNS拡散（LINEで友だちにカードを送る） |
| AI判定 | 写真から図鑑の候補をAI（OpenAI）が提案（無料1日1回／Plus 1日30回）。**トークに写真を送るだけ**でも判定 | Plus課金の主動機 |
| 路上レポート | ロードキル・けが・路上の生き物を報告（保全ポイント+20pt）。正確な位置は行政・保護機関のみに提供 | B2Gデータ契約の中核 |
| セーフドライブ宣言 | 夜の運転前のチェックリスト（1日1回+10pt）。運転中の操作は禁止と明示 | 協賛（損保・レンタカー・交通安全）／自治体施策 |
| クエスト | 季節クエスト（サシバの渡り・クジラ・夏の使者・ウミガメ等）。**協賛枠つき** | 企業協賛の販売単位 |
| 12市町村スタンプラリー | 群島12市町村で記録するとスタンプ。全制覇で記念品 | 広域事務組合・市町村との連携、周遊促進 |
| ポイント交換 | 寄付・ツアー割引・協賛店クーポン・抽選・記念品 | 景品原資＝協賛/自治体。ポイントは購入不可 |
| 体験・ツアー | 認定ガイド等の体験を種・季節にひもづけて紹介 | 送客手数料 |
| 提携先ダッシュボード | 市町村別の記録数、時間帯、月別ロードキル、最新の路上レポート（正確な位置つき） | B2Gライセンスの“見える価値” |

技術構成：LIFF（React）＋ Cloudflare Workers（Hono）＋ D1（データ）＋ R2（写真）＋ Messaging API（Webhook）＋ OpenAI API（AI判定）。
月額固定費が小さく（Workers有料プラン月5ドル〜）、利用量に応じて伸びる構成。

## 4. 収益モデル（7本柱）

### A. B2G：保全データプラットフォーム（最重要・最初に取りに行く）

- **売るもの**：路上レポート（ロードキル・負傷個体）と出現データの収集・可視化・データ提供、普及啓発（セーフドライブ宣言、マナー啓発）、季節キャンペーンの運営。
- **買い手**：奄美群島の12市町村、奄美群島広域事務組合、鹿児島県（大島支庁・自然保護担当）、環境省 沖縄奄美自然環境事務所／奄美野生生物保護センター。
- **価格（仮）**：
  - 市町村ライセンス：年額 60〜120万円（ダッシュボード、データ提供、啓発キャンペーン年2回）
  - 群島一括ライセンス（広域事務組合等）：年額 300〜600万円
  - 委託事業（ロードキル対策の啓発・データ分析レポート・調査イベント）：1件 100〜500万円
- **財源の当て**：奄美群島振興交付金（基本方針で「民間と連携した新しい取組」への支援強化、エコツーリズム推進が明記）、地方創生系交付金（旧デジタル田園都市国家構想交付金。現行制度名・要件は要確認）、環境省の普及啓発・調査予算。
- **最初の一手**：ロードキルの多い奄美大島中南部（大和村・宇検村・奄美市住用・瀬戸内町）で**3か月の無償〜低額実証** → レポート件数・宣言数・アンケートを成果として有償化。

### B. 送客手数料（体験・ツアー）

- 認定エコツアーガイド（奄美群島エコツーリズム推進協議会の認定制度）、奄美クジラ・イルカ協会加盟事業者、マングローブカヌー事業者などを「この生き物に会える体験」として掲載。
- 手数料：成約額の10〜15%（ナイトツアー8,000円なら800〜1,200円／人）。
- **法令**：予約・決済を当社が行うと旅行業登録が必要になりうる。当面は**「紹介のみ（契約・決済は事業者と利用者の直接取引）」の成果報酬型**とし、開始前に観光庁／県の旅行業担当・行政書士に確認する。将来は地域限定旅行業の登録も選択肢。

### C. 企業協賛（ネイチャーポジティブ／CSR／地域貢献）

- **売るもの**：季節クエストの冠協賛（例：「○○と見届ける秋の渡り」）、景品原資の提供、寄付マッチング（100pt＝100円を保全活動へ）、セーフドライブ宣言の冠。
- **価格（仮）**：クエスト協賛 30〜100万円／回、年間スポンサー 150〜300万円。
- **候補**：航空（JALグループ／JAC、Peach、スカイマーク）、レンタカー、損害保険（安全運転と親和性）、地元金融機関、黒糖焼酎メーカー、ホテル。
- 根拠：TNFD（自然関連財務情報開示）に賛同する日本企業は世界最多の160社超（2025年5月）。「生物多様性への貢献を見える形で示したい」ニーズがある。

### D. AMAMI NATURE+（個人課金）

| プラン | 価格（税込・予定） | 狙い |
|---|---|---|
| トリップパス | 480円／7日（自動更新なし） | 旅行者。「旅の間だけAIを使い放題」 |
| 月額 | 480円 | ライトな住民・リピーター |
| 年額 | 3,800円 | 島の生き物好き・ガイド・教員 |

- 特典：AI判定 1日30回（無料は1日1回）、大島紬モチーフの限定カードフレーム、鳴き声ガイド（予定）、売上の一部を保全に寄付（予定）。
- 決済：LIFF内でStripe（カード・Apple Pay・Google Pay等）。LIFFはアプリストア配信ではないため、ストア手数料はかからない。
- AI原価の目安：1回あたり数円（画像＋図鑑リストを入力、短いJSONを出力。図鑑リスト部分はプロンプトキャッシュの対象）。無料枠は1日1回に絞って原価を管理。

### E. 観光キャンペーン運営（DMO・観光協会）

- あまみ大島観光物産連盟（奄美大島のDMO）や各島の観光協会向けに、デジタルスタンプラリー・季節キャンペーン（クジラ、ウミガメ、サシバ）をパッケージ提供。
- 価格（仮）：1キャンペーン 50〜200万円（企画・景品運用・効果レポート込み）。

### F. ふるさと納税・旅先納税との連携

- JALの「旅先納税」（旅行中に寄付→その場で使える電子商品券）は、2024年9月の開始時点で奄美市・喜界町・龍郷町・徳之島町・伊仙町・天城町・和泊町・知名町が対象。**提携ツアーを商品券の使い先に**し、アプリから案内する。
- 体験型返礼品（「ナイトツアー＋AMAMI NATURE+ 年額」等）を市町村と組成。奄美の返礼品は食品・焼酎が中心で、体験型は少ない＝余地がある。

### G. 宿泊施設・レンタカー向け（ゲスト体験・安全運転）

- 客室・チェックイン時・レンタカー貸出時に「友だち追加QR」。夜の運転前にセーフドライブ宣言を促す。
- 価格（仮）：施設あたり月額1〜3万円（施設名入りクエスト、送客レポート、注意喚起の共同発信）。レンタカーは事故・ロードキル抑止という共通利害で協賛にもつなげやすい。

## 6. 収益シミュレーション（仮説）

前提：入域客65万人／年。友だち追加率は空港・ホテル・レンタカー・ガイド経由の導線整備で段階的に上げる。

| | 1年目 | 2年目 | 3年目 |
|---|---:|---:|---:|
| LINE友だち（累計） | 2万 | 6万 | 12万 |
| Plus（有料ユーザー × 平均単価） | 400人 × 1,200円 = **48万円** | 1,800人 × 1,500円 = **270万円** | 4,800人 × 1,600円 = **768万円** |
| 送客（件 × 1,000円） | 600件 = **60万円** | 3,000件 = **300万円** | 8,000件 = **800万円** |
| B2G ライセンス | 2市町村 = **160万円** | 群島一括 = **500万円** | 群島一括＋県 = **800万円** |
| B2G 委託事業 | **200万円** | **500万円** | **800万円** |
| 企業協賛 | 3社 = **150万円** | 8社 = **560万円** | 15社 = **1,200万円** |
| 観光キャンペーン | **100万円** | **300万円** | **500万円** |
| 宿泊・レンタカー | — | 10施設 = **240万円** | 30施設 = **720万円** |
| **売上合計** | **約720万円** | **約2,670万円** | **約5,590万円** |

主な変動費：LINE公式アカウント（スタンダードプラン月15,000円＋超過メッセージ従量）、Cloudflare（Workers有料プラン月5ドル〜＋従量）、OpenAI API（AI判定1回 1円未満〜数円。モデルによる）、決済手数料。景品原資は協賛・自治体負担を原則とする。

**感度の高い変数**：B2G契約の有無（1年目の売上の半分）、友だち追加率（空港・レンタカーでの導線）。→ 1年目は「ロードキル実証で成果を出してB2Gを取る」ことに集中する。

## 9. リスクと対策

| リスク | 対策 |
|---|---|
| 希少種の場所が広まり、盗掘・密猟を助長 | 希少種は座標を保存しない（端末・サーバーの両方で強制）。共有画像に地域名も出さない。正確な位置は契約した行政・研究機関にのみ提供 |
| AIの誤判定・図鑑の誤り | 候補と確からしさを表示し最終判断はユーザー。図鑑データは監修を受けるまで「β版」と明示。保護区分は公式情報で確認 |
| ポイント目当ての不正記録 | 同一写真の使い回し検知、1日の記録上限、景品は審査制。ポイントは購入不可・換金不可 |
| 運転中の操作 | 路上レポートとセーフドライブ画面で「停車してから・同乗者が」を明示。走行中の通知を送らない |
| 景品表示法・資金決済法 | ポイントは無料の行動でのみ付与し購入不可（前払式支払手段に当たらない設計）。取引に付随しない景品として運用し、高額景品・抽選は開始前に専門家確認 |
| 旅行業法 | 紹介型（契約・決済は事業者と直接）で開始。開始前に行政・行政書士へ確認 |
| 個人情報・位置情報 | 利用目的（行政への提供を含む）をプライバシーポリシーで明示し同意取得。提携先への提供はデータ提供契約で範囲・目的を限定 |
| 季節変動 | 冬（クジラ）・夏（ウミガメ・ナイト）・秋（渡り）の季節クエストで年間を平準化 |
| LINEプラットフォーム依存・配信コスト | 一斉配信は絞り、応答メッセージとリッチメニュー中心で運用。Webでも動く（PWA）構成にしてある |

## 10. 監修体制（公開前に必ず）

- 図鑑62種の解説・分布・季節・保護区分を、環境省 奄美野生生物保護センターや研究者・認定ガイドに監修いただく（監修料は委託費・協賛費に含めて設計）。
- 保護区分（天然記念物・国内希少野生動植物種など）は環境省・文化庁・県の最新の公式一覧で照合する。
- 観察マナー・夜間ルールは県・環境省の最新ルールと文言を合わせる。
