# デザインシステム「アマミ図鑑クエスト」

AMAMI NATURE の画面の決まり。ゲームのように「見つけて、ゲットして、集めて、レベルが上がる」気持ちよさで、外に出て生き物を探すきっかけを作る。

## 0. 決定の経緯

- 2026-10: 前のデザインシステム「瑠璃の野帳」（白い紙と墨、瑠璃 1 色の静かな図鑑）を廃止した。依頼は「もっとドパガキ向けの、ポケモンのゲームみたいな UI/UX」。中高生〜若い大人が、ゲームと同じ手ざわりで遊べることを優先する。
- 方向: 空色の盤面に白いパネル、押せる厚みのあるボタン、生き物のタイプ（分類）とレア度の色、丸ゴシックの太い文字、ゲットの演出・効果音・紙吹雪・レベルアップ。
- ポケモンそのもの（モンスターボール、キャラクター、ロゴ、専用フォント、「ポケモン」「図鑑」以外の固有名詞）は使わない。手ざわりだけを借り、図柄はすべてオリジナル（§9）。

## 1. 原則

1. **ゲットが主役。** 記録の瞬間に、演出・音・ふるえ・紙吹雪・ポイント・XP・レベルアップ・バッジをまとめて返す（§6）。
2. **毎日もどってくる理由。** きょうのミッション、連続日数、イベントクエスト、図鑑のコンプ率（§5）。
3. **色に意味を持たせる。** タイプは 6 色、レア度は 4 色。それ以外の色は瑠璃（主な操作）、赤（撮る）、金（ポイント）、緑（達成）だけ。
4. **押せるものは厚い。** ボタン・カード・タイルは下に 3〜4px の縁があり、押すと沈む。押せないものは平ら。
5. **生き物と人の安全が先。** 刺激の強い仕掛けでも、保全のルールは曲げない（§8）。

## 3. 文字

| 用途 | 書体 | 太さ |
|---|---|---|
| 本文・見出し | M PLUS Rounded 1c | 500 / 700 / 800 / 900 |
| 数字・英字のラベル（Lv、No.、GET!、pt） | Lilita One（`.num`、`font-num`） | 400 |
| メッセージ窓 | DotGothic16（`font-pixel`、`.msg-window`） | 400 |

Google Fonts から読み込む（`index.html`）。文字サイズは `tailwind.config.js` の `display`(30/900) `title`(24/800) `section`(19/800) `headline`(17/700) `body`(15) `callout`(15) `sub`(13) `tile`(12/800) `caption`(11/700) `tab`(11/800) と、数字の `num-xl`(48) `num-kpi`(30) `num-l`(24)。行のタイトルは 700、見出しは 800〜900。和文の改行は `line-break: strict` と BudouX（`<Phrase>`）。

## 4. 形と部品

- 角丸: `xs` 10、`thumb` 12、`sm` 14、`md` 18、`lg` 24、`xl` 28。
- `.panel`: 白い面、2px の `line` の枠、4px の `edge` の厚み。`.pressable` で押すと沈む。
- ボタン（`button()`）: `primary`（瑠璃）、`secondary`（白）、`gold`（交換・お祝い）、`capture`（撮る）、`line`、`danger`、`on-stage`（夜空の上）、`text`。高さ 56 / 44。文字は 900。
- リスト: グループ（`Group`）の中は線で区切る。グループの外の `ListRow` は 1 行ずつのカード。
- チップ: 丸いピル、選択中は瑠璃（タイプのチップはタイプの色）。
- 進み具合: `XPBar`（紺の溝に斜線が流れるバー。xp / brand / gold）、`Ring`（コンプ率）、`ProgressBar`。
- `game.tsx`: `TypeBadge`、`Stars`、`LevelBadge`、`XPBar`、`Coin` / `CoinCount`、`Ring`、`MessageWindow`、`Sparkles`、`TYPE_META`。
- `Player.tsx`: `PlayerHud`（アバター・レベル・称号・コイン・XP）、`PlayerAvatar`。
- 図鑑タイル（`SpeciesTile`）: 記録済みはタイプの色の枠と写真と名前。未発見は「？」のプレート（幻は金）と名前「？？？」（§5.1）。シルエットが届けば「？」の代わりに紺の影になる。24 時間以内は NEW。
- 図鑑カード（`CollectibleCard`）: トレーディングカード。名前と No.、写真の窓、タイプと星、ニックネーム、図鑑の説明、日付と市町村。めずらしい・幻はホロと傾き。
- バッジ（`BadgeEmblem`）: ジムバッジのようなメダル。記録の節目＝金の六角、生き物＝紫の円、島と季節＝緑のひし形、守る＝赤の盾、幻＝金。
- タブバー: 下に浮いた白いバー。中央に赤い「きろく」ボタン（波紋が広がる）。

## 5. ゲームの仕組み

| 仕組み | 中身 | 実装 |
|---|---|---|
| ポイント（pt） | 記録・路上レポート・宣言・クエストで貯まる。交換できる。購入できない | `lib/progress.ts` |
| レベル | 累計ポイントから。Lv L に必要な累計は 10·L·(L−1)（Lv2=20、Lv5=200、Lv10=900、Lv20=3,800、上限 50）。はじめは早く上がる | `levelFor()` |
| 称号 | 島のたまご → 見習い観察者 → … → シマの守り人 | `RANKS` |
| きょうのミッション | 記録 1 回、図鑑で 3 種しらべる、セーフドライブ宣言。全部で「コンプリート！」（1 日 1 回の紙吹雪）。ポイントは付かない | `lib/missions.ts` |
| 連続日数 | アプリを開いた日が続いた数（炎のアイコン）。途切れても罰はない | `visitStreak()` |
| イベントクエスト | 季節の期間限定。報酬ポイント。協賛の販売単位 | `data/quests.ts` |
| バッジ | 16 個。バッジケースに並べる | `BADGES` |
| 図鑑 | 62 種、No.001〜062、コンプ率 | `data/species.ts` |

### 5.1 まだ見つけていない種（「？？？」）

ゲームの図鑑と同じく、記録（ゲット）するまで名前を伏せる。ゲットの演出のメッセージ窓で初めて名前がわかる。

| 場所 | 未発見の時 |
|---|---|
| 図鑑のタイル、ホームの「会えるかも」のカードと一覧 | 名前は「？？？」、絵は「？」かシルエット（参考写真も出さない） |
| 種の詳細 | 名前・ヘッダー・`document.title` は「No.007 ？？？」、学名の代わりに「ゲットすると、名前と説明がわかるよ」、英名は「？？？」、図鑑の説明は鍵のパネル（「ゲットすると読めるよ」）、シマの話は出さない |
| 図鑑の検索 | 名前で見つかるのはゲットした種だけ。未発見の種は No. の番号（「12」「No.012」）で探す（`searchZukan()`） |
| 読み上げ | 「？？？」は読ませず「まだ見つけていない生き物」と読む（`SpeciesName` の `hidden`、`HIDDEN_NAME_LABEL`） |

隠さないもの:

- 安全と保全の情報: 毒のある種の「毒あり・近づかない」のチップ（名前のすぐ下）と注意、観察マナー、位置をぼかす注意。
- 探すためのヒント: タイプ、レア度、固有種・夜行性・天然記念物のチップ、見られる季節、さがしかたのコツ。**コツ・マナー・危険の文に、その種の名前を書かない**（`tests/game.test.ts` が確かめる）。
- 本当の名前を出す所: 記録の名前を選ぶ段階（見た生き物を選ぶため）、クエスト・季節の一文・バッジや景品の説明、自分の記録（記録の詳細・図鑑カード・共有画像）、パートナー向けのダッシュボード、体験の紹介。

## 6. 演出・音・ふるえ

- **ゲット！**（`CardReveal`）: 夜空の舞台にカードの裏面が落ちる → 3 回ゆれる（「なにが でるかな……？」）→ 光って表に返る → GET!（再記録は NICE!）と紙吹雪 → メッセージ窓「やったね！ ○○を ゲットした！」→ ポイントのコインと XP バー → レベルアップ → 図鑑に とうろく（NEW、n/62）・クエスト CLEAR → 閉じるとバッジ GET!。「スキップ ›」やカードを押すと結果まで飛ばせる。
- 効果音: ZzFX でその場で合成（音声ファイルなし）。`tap` `coin` `shake` `burst` `get` `rare` `levelup` `badge` `mission` `whoosh`。マイページの「効果音・バイブ」で止められる（`settings.sound`）。
- ふるえ: `navigator.vibrate`（Android のみ。iPhone は非対応）。
- 紙吹雪: canvas-confetti。ゲット（レア度で色と量が変わる、幻は星形）、レベルアップ、ミッションコンプリート、ポイント交換、バッジ。
- 常に動くもの: 記録ボタンの波紋、XP バーの斜線、レア以上のタイルの光、キラキラ。
- 動きを減らす設定（`prefers-reduced-motion`）では、落下・ゆれ・紙吹雪を止め、すぐ結果を出す。

## 8. 安全と保全のための約束（刺激の強い仕掛けでも守ること）

1. **お金で買えるガチャ・ポイントは作らない。** ポイントは無料の観察行動でのみ貯まり、購入・換金できない（景品表示法・資金決済法、コンプガチャの禁止）。
2. **生き物に近づくほど得をする仕組みを作らない。** 距離・接写・巣の発見にボーナスを付けない。
3. **希少種の場所は出さない。** 位置は自動でぼかし、共有画像に市町村名も載せない（`sensitive`）。
4. **夜の運転を急がせない。** 夜のミッションや時間制限は作らない。夜はセーフドライブを出す。
5. **連続日数は罰にしない。** 途切れてもポイントや称号は減らない。通知で煽らない。
6. **演出は飛ばせる。** スキップ、動きを減らす設定、効果音オフに必ず対応する。
