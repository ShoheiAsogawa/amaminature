# 利用規約・プライバシーポリシーを公開する前の確認

`src/data/legalTexts.ts`（利用規約・プライバシーポリシー）と `src/data/consentTexts.ts`（路上レポートの同意・お問い合わせ・退会）は、
コードの実際の動きにあわせて書いた**案**です。公開の前に、会社で次を決め、弁護士に確認してもらってください。
確認が終わったら `src/data/company.ts` の `LEGAL_DRAFT` を `false` にします（画面の「確認中の案」の表示が消える）。

`npm run check:legal` で、埋まっていない項目を確かめられます。

## 会社が決めて埋めるもの（`src/data/company.ts`）

- [ ] 住所（`address`）・代表者（`representative`）
- [ ] お問い合わせ・開示等の請求の窓口のメール（`email`）。個人のアドレスではなく、会社の共有の窓口にする
- [ ] 返信の目安（`replyTime`）
- [ ] 個人情報の取扱いの責任者（`privacyOfficer`、部署名か役職）
- [ ] 裁判の管轄（`court`）

## 弁護士に確認してもらうこと

- [ ] **AI判定（Anthropic, PBC・米国）**：外国にある第三者への提供（個人情報保護法 28 条）として、AI判定を使う前に同意をとる画面が必要。**この画面はまだない**ので、同意の画面ができるまで AI判定を本番で有効にしない（`ANTHROPIC_API_KEY` を入れない）。Anthropic の API のデータの保存期間・学習への利用の条件を確かめて、プライバシーポリシー 5 に書く
- [ ] **Cloudflare（米国）**：委託として扱うか、クラウド例外（個人データを取り扱わない契約）として扱うかと、外的環境の把握の書き方（プライバシーポリシー 5・9）
- [ ] **外部送信規律（電気通信事業法 27 条の 12）**：本サービスが対象になるか。対象なら、プライバシーポリシー 6 の書き方で足りるか
- [ ] **路上レポートの第三者提供**：提供先（提携する自治体・保護団体）の名前を公表するか。同意の文面（`ROAD_CONSENT`）で足りるか
- [ ] **未成年**：何歳から使えるか、保護者の同意のとり方（いまは「保護者の同意を得てから」と書いているだけで、年齢を聞く画面はない）
- [ ] **手数料**：開示等の請求に手数料をとらない（`CONTACT.requests` に「手数料はいただきません」と書いている）でよいか
- [ ] **ポイント**：サービス終了の 1 か月前に知らせ、その日にポイントがなくなる（利用規約 第 4 条・第 14 条）でよいか。資金決済法の前払式支払手段に当たらないこと（無償で付与・購入できない）
- [ ] **景品**：景品表示法の上限（懸賞・総付景品）に合っているか。抽選の当選のお知らせの方法（利用規約 第 5 条）
- [ ] **責任の制限**：消費者契約法 8 条・10 条で無効にならないか（利用規約 第 15 条は「軽い過失の時は直接かつ通常の損害に限る」としている）
- [ ] **規約の変更**：民法 548 条の 4（定型約款の変更）の手続き（利用規約 第 16 条）

## 公開の手続き

- [ ] LINE Developers の LINE ログインチャネルに、プライバシーポリシーと利用規約の URL（`https://<ドメイン>/privacy`・`/terms`）を登録する
- [ ] R2 の LINE のトークの写真の自動削除（7 日）を設定し、確かめる（プライバシーポリシー 8 に書いている）
  ```bash
  npx wrangler r2 bucket lifecycle add amami-nature-photos inbox-expire inbox/ --expire-days 7
  npx wrangler r2 bucket lifecycle list amami-nature-photos
  ```
- [ ] 文面を変えたら `src/data/legalVersions.ts` の版（日付）を上げる。利用者には次に開いた時に、もう一度同意してもらう画面が出る
