# 運営の手順書（問い合わせ・開示・削除・漏えい）

AMAMI NATURE を運営するスタッフ向けの手順です。管理画面は `/admin`（管理キーでログイン）。
法令の判断が必要な時は、この手順書だけで決めず、責任者と専門家に相談してください。

## 1. お問い合わせを受けたら

1. メール（`src/data/company.ts` の `email`）で受け付ける。LINE 公式アカウントのトークに来た時も同じ流れで扱う。
2. お問い合わせ番号（`AN-XXXXXXXX`）が書かれていれば、管理画面の「ユーザー」で番号を入れて探す。
   - 番号はマイページの「お問い合わせ」と、お問い合わせ画面に出ている。
   - デモモードの利用者は番号がない。運営は記録を持っていないので、端末での操作（マイページの「この端末のデータを消去」）を案内する。
3. 返信の目安（`replyTime`）を守る。すぐに答えられない時も、受け付けたことをまず返す。

## 2. 開示・訂正・利用の停止・削除などの請求

個人情報保護法で、本人は次を請求できます：利用目的の通知、開示、訂正・追加・削除、利用の停止・消去、第三者への提供の停止、第三者への提供の記録の開示。
**遅滞なく**対応します（目安：受け付けから2週間以内。延びる時は理由と見込みを本人に伝える）。手数料はとりません。

### 本人の確認

- お問い合わせ番号に加えて、次のどれかで確かめる。
  - LINE 公式アカウントのトークから、同じ内容を送ってもらう（LINE Official Account Manager のチャットに出る表示名と、管理画面の「LINE: 表示名」が同じか確かめる）。
  - LINE の表示名・レンジャーネーム・最近の記録の内容（生き物と日にち）を答えてもらい、管理画面と照らし合わせる。
- 確かめられない時は、請求に応じない理由を本人に伝える。

### 開示（書き出し）

1. 管理画面の「ユーザー」で利用者を探し、［書き出す（開示）］を押す。JSON ファイルが保存される。
2. 写真が必要と言われたら、「記録チェック」でその利用者の写真を確かめ、本人に渡す。
3. ファイルは、パスワードつきの ZIP などで本人にだけ渡す。メールの本文にパスワードを書かない。
4. 渡した日と方法を記録する（下の「対応の記録」）。

### 訂正・利用の停止

- ニックネームやメモの訂正は、本人がアプリの記録の詳細で直せることを案内する。
- 路上レポートの正確な位置の提供をやめたい時は、マイページの「路上レポートの位置の提供」で同意をやめられることを案内する（すでに提携先に渡した分は取り戻せない）。
- 不正の疑いで取り消した記録は、管理画面の「記録チェック」の［取り消しを戻す］で戻せる。

### 削除

1. 本人が LINE で連携していて、自分で操作できるなら、マイページの「退会（クラウドのデータを消す）」を案内する。
2. 運営が消す時は、管理画面の「ユーザー」で利用者を探し、［データを消す］を押す。次のものが消える。
   - アカウント、記録、写真（R2 の `photos/<ID>/`）、LINE のトークの写真（`inbox/<ID>/`）、共有画像（`shares/`）、路上レポート、セーフドライブ宣言、AI判定の回数
   - 交換の申請の記録は、精算のために利用者と結びつかない形で残る（`user_id` が `deleted:…` に変わり、メモは空になる）
   - 退会前のログインは使えなくなる（`deleted_users` に LINE ID のハッシュだけを残す）
3. 操作ログ（管理画面の「操作ログ」）に、お問い合わせ番号と、消した写真の数が残る。
4. 交換を申請中の景品があれば、発送を止める。
5. すでに CSV で自治体・保護団体に渡した路上レポートは、取り戻せないことを本人に伝える。

### 対応の記録

請求を受けた日、本人確認の方法、対応した内容と日、対応した人を、社内の記録（表計算など）に残す。LINE ID は書かず、お問い合わせ番号で書く。

## 3. 漏えいなどが起きた時（または、その疑いがある時）

1. **すぐに止める**：管理キー・Cloudflare のトークン・LINE のチャネルシークレットなど、漏れた可能性のある鍵を作り直す（`npm run admin:key`、`wrangler secret put`）。
2. **責任者に連絡する**。何が・いつから・何人分か・どこから漏れたかを調べ、記録を残す。
3. **個人情報保護委員会への報告と本人への通知**が必要か判断する（個人情報保護法 26 条）。次に当たる時は報告が必要：
   - 要配慮個人情報が含まれる、財産的な被害のおそれがある、不正の目的によるおそれがある、1,000 人を超える。
   - 報告は、知ってから**速やかに（おおむね 3〜5 日以内）速報**、**30 日以内（不正の目的によるものは 60 日以内）に確報**。
   - 本人には、状況に応じて速やかに知らせる。知らせることが難しい時は、アプリの画面で公表するなどの代わりの措置をとる。
4. 原因を直したら、再発を防ぐ対策を記録する。

## 4. 路上レポートを自治体・保護団体に渡す時

- 管理画面の「路上レポート」の［CSV］は、運営が取り消したレポートを含まない。
- 正確な位置は、提供に同意した利用者のレポートにだけ入っている（同意のないものは、サーバーが位置を受け取らない）。
- CSV には正確な位置が入るので、渡す相手と方法を決めて渡し、渡した日と相手を記録する。メールに添付する時はパスワードをかける。
- 提携先には、提携先のダッシュボード（`/partners`、提携先ごとのキー）を使ってもらう方が安全。キーは管理画面の「提携先」で発行・無効化する。

## 5. 鍵の管理

- **管理キー**：パスワード管理アプリに保存し、使う人だけに渡す。人が抜けた時や漏れた疑いがある時は `npm run admin:key` で作り直し、表示されたコマンドでサーバーに登録する（古いキーはすぐ使えなくなる）。
- **Cloudflare の API トークン**：必要な権限だけにし、期限をつける。チャットやメールに書かない。
- **LINE のチャネルシークレット・アクセストークン、Anthropic の API キー**：`wrangler secret put` でだけ入れる。
